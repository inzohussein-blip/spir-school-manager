# سبير — إدارة المدارس (Spir School Manager)

منصة عربية (RTL) لإدارة المدارس الحكومية والأهلية العراقية، تُؤجَّر برمز تفعيل لكل مدرسة:
محطات تعمل على الحاسوب نفسه بلا إنترنت، ولوحة إدارة كاملة مدفوعة لاحقاً، ومدير رموز للمالك.

- **الإطار:** Next.js 16 (App Router) + React 19 + TypeScript، Tailwind v4 (عربي RTL، فاتح/داكن)
- **البيانات:** المحطات في المتصفح (IndexedDB) ومشتركة بين المحطات؛ الرموز والإدارة على Postgres
- **الخطة الكاملة:** [`docs/SCHOOL_PLAN.md`](docs/SCHOOL_PLAN.md)

## حالة التنفيذ

| المحطة | المسار | الحالة |
|---|---|---|
| الإعداد والعام الدراسي | `/setup` | ✅ بيانات المدرسة ونوعها، العام والفصول، المنهج العراقي الافتراضي، الحصص والقاعات |
| الطلاب والتسجيل | `/students` | ✅ السجل والبحث، إضافة جماعية، الترفيع السنوي |
| الصفوف والفصول والجداول | `/classes` | ✅ الشعب، توزيع الطلاب، جدول كل شعبة مع كشف التعارض، طباعة الكل |
| الكادر التدريسي وجدول المدرسين | `/teachers` | ✅ الملفات والنصاب، جدول المدرس المشتق، أحمال الحصص |
| النتائج والشهادات | `/results` | ✅ إدخال الدرجات، قواعد التقويم، كشف النتائج والرتب، شهادات (نجاح/تخرج/بطاقة/تقدير) لطالب أو لمجموعة بأرقام تسلسلية |
| الإجازات والعطل | `/leaves` | ✅ تقويم العطل، إجازات الكادر بالأرصدة وكتاب الإجازة، إجازات الطلاب وكتاب العذر |
| الخطة السنوية | `/plan` | ✅ خطط لكل مدرس ومادة وصف موزعة على الأسابيع بعد العطل، متابعة الإنجاز وتقرير التأخر |
| الحضور والغياب | `/attendance` | ✅ تحضير الشعبة والكادر وتقرير الغياب مع الإنذارات |
| الأقساط الشهرية (الأهلية) | `/fees` | ✅ قسط الصفوف والخصومات، المستحقات الشهرية، الدفعات ووصل القبض، المتأخرون |
| لوحة التحكم والتحليلات | `/dashboard` | ✅ مؤشرات الطلاب والحضور، رسوم بيانية، تقدم الخطط، تنبيهات |
| لوحة متابعة الخطط | `/plan/board` | ✅ سحب وإفلات الوحدات بين «لم تبدأ / قيد التنفيذ / مكتملة» |
| لوحة الإدارة على الإنترنت | `/portal` | ✅ دخول برمز المدرسة وحساب بصلاحية (مدير / محاسب / مدرس)، عرض للقراءة فقط لبيانات الحواسيب المتزامنة؛ الحسابات من «الإعداد ← حسابات الويب» |
| المزامنة | `/sync` | موروثة من مشروع المختبرات |
| مدير الرموز | `/license` | موروث؛ يفعّل المحطات المدرسية بالرمز |

## التصميم

واجهة خضراء هادئة: قائمة جانبية عائمة، شريط علوي (بحث ⌘K، تنبيهات، المظهر)، بطاقات مستديرة، وتبويبات لصفحات كل محطة. المكونات في `src/components/school/` (`AppShell` و`charts` و`Palette`). لقطات بيانات تجريبية: `node tests/e2e/shots.cjs` (يستعمل `tests/e2e/seed.cjs`).

## التشغيل

```bash
npm ci
npm run dev        # http://localhost:3000/welcome
npm run build && npm start
BASE=http://localhost:3000 node tests/e2e/school.flow.cjs   # اختبار المتصفح على خادم يعمل
```

## لوحة الإنترنت (`/portal`)

تعتمد على «المزامنة التلقائية»: الحاسوب يرفع سجلات المدرسة إلى مكانها على الخادم، واللوحة تقرؤها (`src/lib/portal/`). الحسابات (`school.portalUsers.v1`) بكلمات مرور PBKDF2 تُنشأ في محطة الإعداد وتتزامن مع البيانات؛ الخادم لا يرسل لكل صلاحية إلا ما يحق لها (المدرس بلا أقساط ورواتب، المحاسب بلا نتائج). يلزم أن يتضمن رمز المدرسة وحدة «لوحة الإدارة الكاملة». اختبار شامل: `LICENSE_ADMIN_PASSWORD=test1234 AUTH_SECRET=… npm start` ثم `node tests/e2e/portal.flow.cjs`.

## البنية

- `src/lib/school/stations.ts` — سجل المحطات (الاسم، المسار، اللون، الوصف).
- `src/lib/school/store.ts` — «الملف المدرسي» المشترك (العام، الصفوف، المواد، الحصص، الطلاب، الشعب، الجدول، المدرسون) وكشف التعارض والنسخ الاحتياطي.
- `src/components/school/` — إطار المحطة (`StationFrame`: الترخيص والرمز السري والمظهر)، القائمة الجانبية، عناصر الواجهة، الطباعة والجدول.
- إضافة محطة: سجّلها في `stations.ts` و`lib/license/modules.ts` و`SchoolSidebar.tsx`، ثم أضف `src/app/<id>/layout.tsx` بـ `StationFrame`.
- بقايا من مشروع المختبرات تحتاج مراجعة لاحقاً: واجهات `/api/license` وملفات `supabase/migrations` و`docs/PROJECT_REFERENCE.md` ونصوص `/license` والمزامنة وصفحة الشروط (`WelcomeFooter`)؛ وملاحظة: ما زالت لوحة إدارة الإنترنت (المرحلة 8) غير مبنية، وجداول `lib/license/adminDb.ts` بأسماء المختبرات.
