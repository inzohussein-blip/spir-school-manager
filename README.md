# سبير — إدارة المدارس (Spir School Manager)

منصة عربية (RTL) لإدارة المدارس الحكومية والأهلية العراقية، تُؤجَّر برمز تفعيل لكل مدرسة:
محطات تعمل على الحاسوب نفسه بلا إنترنت، ولوحة إدارة كاملة مدفوعة لاحقاً، ومدير رموز للمالك.

- **الإطار:** Next.js 16 (App Router) + React 19 + TypeScript، Tailwind v4 (عربي RTL، فاتح/داكن)
- **البيانات:** المحطات في المتصفح (IndexedDB) ومشتركة بين المحطات؛ الرموز والإدارة على Postgres
- **الخطة الكاملة:** [`docs/SCHOOL_PLAN.md`](docs/SCHOOL_PLAN.md)

## حالة التنفيذ

| المحطة | المسار | الحالة |
|---|---|---|
| الإعداد والعام الدراسي | `/setup` | ✅ بيانات المدرسة ونوعها، العام والفصول، المنهج العراقي الافتراضي، الحصص والقاعات |
| الطلاب والتسجيل | `/students` | ✅ السجل والبحث، إضافة جماعية، الترفيع السنوي |
| الصفوف والفصول والجداول | `/classes` | ✅ الشعب، توزيع الطلاب، جدول كل شعبة مع كشف التعارض، طباعة الكل |
| الكادر التدريسي وجدول المدرسين | `/teachers` | ✅ الملفات والنصاب، جدول المدرس المشتق، أحمال الحصص |
| النتائج والشهادات | `/results` | ⏳ المرحلة 4 |
| الإجازات والعطل | `/leaves` | ⏳ المرحلة 5 |
| الخطة السنوية | `/plan` | ⏳ المرحلة 6 |
| الحضور والغياب | `/attendance` | ⏳ المرحلة 5 |
| الأقساط الشهرية (الأهلية) | `/fees` | ⏳ المرحلة 7 |
| المزامنة | `/sync` | موروثة من مشروع المختبرات |
| مدير الرموز | `/license` | موروث؛ يفعّل المحطات المدرسية بالرمز |

## التشغيل

```bash
npm ci
npm run dev        # http://localhost:3000/welcome
npm run build && npm start
BASE=http://localhost:3000 node tests/e2e/school.flow.cjs   # اختبار المتصفح على خادم يعمل
```

## البنية

- `src/lib/school/stations.ts` — سجل المحطات (الاسم، المسار، اللون، الوصف).
- `src/lib/school/store.ts` — «الملف المدرسي» المشترك (العام، الصفوف، المواد، الحصص، الطلاب، الشعب، الجدول، المدرسون) وكشف التعارض والنسخ الاحتياطي.
- `src/components/school/` — إطار المحطة (`StationFrame`: الترخيص والرمز السري والمظهر)، القائمة الجانبية، عناصر الواجهة، الطباعة والجدول.
- إضافة محطة: سجّلها في `stations.ts` و`lib/license/modules.ts` و`SchoolSidebar.tsx`، ثم أضف `src/app/<id>/layout.tsx` بـ `StationFrame`.
- بقايا من مشروع المختبرات تحتاج مراجعة لاحقاً: واجهات `/api/license` وملفات `supabase/migrations` و`docs/PROJECT_REFERENCE.md` ونصوص `/license` والمزامنة وصفحة الشروط (`WelcomeFooter`)؛ وصفحة «عن التطبيق» حُذفت وستُعاد كتابتها.
